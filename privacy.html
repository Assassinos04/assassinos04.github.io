Privacy Policy

Last updated: 19 November 2026

GTA Shorts Uploader ("the app") is a personal tool that uploads videos to the owner's own YouTube channel (@cicadababe). It has no other users.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the app uses

With the channel owner's permission (Google OAuth, scope youtube), the app uses the YouTube Data API to upload videos and set their title, description and tags. It does not read, collect or store any other personal data, and it does not access data of any other person.

Storage and sharing

The only stored item is the OAuth refresh token Google issues for the owner's account, kept as a private secret so uploads can run. No YouTube data is stored or displayed. No data is sold or shared with third parties. The app uses no cookies.

Deletion and revoking access

Access can be revoked at any time on the Google security settings page. When access is revoked or the app is no longer used, the stored token is deleted within 7 days. No other data is held, so nothing else needs deleting.

Contact

Questions can be sent through the contact details on the YouTube channel's About page.
