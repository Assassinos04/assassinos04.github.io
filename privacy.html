Privacy Policy

Last updated: 19 November 2026

GTA Shorts Uploader ("the app") is a personal tool that uploads videos to the owner's own YouTube channel. It has no other users.

What data the app uses

With the channel owner's permission (Google OAuth), the app uses the YouTube Data API to upload videos and set their title, description and tags. It does not read, collect or store any other personal data, and it does not access data of any other person.

Storage and sharing

The only stored item is the access token Google issues, kept privately so uploads can run. No data is sold or shared with third parties.

YouTube and Google

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See the Google Privacy Policy. Access can be removed at any time at Google account permissions.

Contact

Questions can be sent through the contact details on the YouTube channel's About page.
